Tetris Game (Python)

This project is a classic implementation of the game Tetris, developed in Python with two gameplay modes:

Time Attack Mode – play against the clock and aim for the highest score within a limited time
Free Mode – play at your own pace with no time restrictions

The game is built using Python and utilizes the following libraries:

pygame – for game development and rendering
random – for generating random Tetris pieces
time – for handling timing mechanics
os – for system-level operations
